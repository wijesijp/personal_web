# Personal Portfolio — Janaka Wijesena

Personal portfolio site for Janaka Wijesena, a game developer and software engineer based in Sri Lanka.

Static HTML/CSS, no build step or dependencies — just open `index.html` in a browser.

## Pages

- `index.html` — Home
- `career.html` — Career history
- `education.html` — Education
- `games.html` — Games
- `interactive.html` — Interactive/research demos
- `projects.html` — Full project history, grouped by employer
- `research.html` — Publications and exhibitions
- `skills.html` — Technical skills

## Structure

- `assets/style.css` — shared stylesheet (sidebar layout, light/dark theme)
- `assets/profile.png` — profile photo
